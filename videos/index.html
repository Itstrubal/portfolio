Interaction flow

  1. Curated Input

    Image references: generated character and background, clothing references, or generate a new character

  2. Image Generation

    A ComfyUI workflow is triggered with engineered prompts. A frame is generated in the structure of a gameplay frame

  3. Items Selection

    The user selects which clothing items will be applied; the indexes of the selected items are sent to the video generation ComfyUI workflow

  4. Video Generation

    A ComfyUI workflow is triggered. The workflow includes LLMs, a VL model, custom nodes and finally Seedance video generation

  5. Final Video Export

Video Ads Variation Pipeline

Scaling Creatives With AI

50 ads per week for winning ads or for A/B testing.

The challenge

Generating video ad variations one by one meant tweaking a highly detailed prompt by hand, every time.

The process relies on several different models, each with its own interface, so the creatives had to keep jumping between tools to produce a single ad.

System architecture

The generative AI workflow is designed and run in ComfyUI.

Models

FLUX.1 [dev]
Image generation
FLUX.2 [klein]
Image editing
Qwen2.5-VL
Vision-language model that generates a description from an image
Seedance 2.0
Video generation
Claude and Nano Banana
Through ComfyUI partner nodes
Custom node
A node I created that edits and structures the video prompt

Human in the loop

  • The starting point is creative. Every run begins with a key creative asset or idea from the team

  • Designers cherry-pick the strongest assets from the raw output

  • Every output is checked. Generated content is reviewed for prompt drift, glitches and artifacts

How much is automated depends on the brief.

Open briefMore automation, less review

Strict briefLess automation, more human review

Automation
Human review

Enablement and support

ComfyUI workflows are too complex for most non-technical users. I turned the workflow into a simple, user-friendly web app, designed and built with Claude Design and Claude Code. After launch, I kept supporting the team and iterating on the app as they used it, adding features and onboarding new users.

Users

UA leads, creative leads, motion designers

Limitations

The generated content needs to be validated to weed out prompt drifts, glitches and artifacts

Next steps

Pushing the content to the asset manager – each variant receives a unique tracking ID and is monitored for performance
